# Licença

O VARHub é **software livre e de código aberto**.

| Parte | Licença |

| Exemplos WebXR em `public/webxr-samples-main` | MIT, © 2018 The Immersive Web Community Group (arquivo `LICENSE.md` na pasta) |

## Por que MIT

A MIT é simples e permissiva: permite usar, modificar e distribuir, inclusive comercialmente, mantendo o aviso de copyright. Foi escolhida para facilitar a colaboração e o reaproveitamento acadêmico do projeto.
