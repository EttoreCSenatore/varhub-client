# Segurança / Security

**PT-BR** — Encontrou uma vulnerabilidade? Use o [relato privado de vulnerabilidades do GitHub](https://github.com/EttoreCSenatore/varhub-client/security/advisories/new). Não abra issue pública com detalhes. Não envie dados pessoais reais.

**EN** — Found a vulnerability? Use GitHub's [private vulnerability reporting](https://github.com/EttoreCSenatore/varhub-client/security/advisories/new). Please do not open a public issue with details, and do not send real personal data.

---

## Supported versions and dependencies

Only the newest release receives fixes; installations are expected to update (see the upgrade docs). Versions are pinned, and GitHub's Dependabot opens a pull request with the fix as soon as an advisory is published, and proposes new versions weekly (npm) or monthly (GitHub Actions and Docker images). The license audit runs in CI. You will get an answer within 7 days; once a fix is released the advisory is published with credit to you, unless you prefer otherwise.

Versões suportadas: só a mais recente recebe correções. O Dependabot abre um PR assim que há um aviso de segurança. Resposta em até 7 dias.
