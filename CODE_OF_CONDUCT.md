# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, welcome people of every background and experience level, assume good faith, accept feedback
graciously, and do not harass or discriminate.

Report unacceptable behavior to the maintainer, [@EttoreCSenatore](https://github.com/EttoreCSenatore), by private message on GitHub.
Reports are handled confidentially.

---

Este projeto segue o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/):
respeito, acolhimento de todas as pessoas, boa-fé, receber críticas com abertura e nada de assédio ou discriminação.
Denúncias vão por mensagem privada no GitHub para [@EttoreCSenatore](https://github.com/EttoreCSenatore), com sigilo.
